# Daal — canonical brand assets

This directory is the single source of truth for the Daal app icon
and brand mark. All platform icons (Tauri desktop, Android, iOS, web
favicon) are **generated** from these source files; do not commit
hand-edited per-platform sizes that diverge from these.

Daal is the canonical name for the mark (Persian mythical eagle).
Do not refer to it as "phoenix" anywhere in the codebase.

## Layout

```
client-shared/branding/
├── README.md                ← this file
├── sources/                 ← committed canonical inputs
│   ├── daal-logo.svg
│   ├── daal-logo-master.png         (3891×3891 raster master)
│   ├── daal-icon-bg.png             (512×512 white-bg app icon)
│   ├── daal-icon-nobg.png           (512×512 transparent)
│   ├── daal-icon-bg-{180,192}.png   (iOS/Android xxxhdpi direct fits)
│   ├── daal-icon-nobg-{180,192}.png
│   └── daal-favicon{-16,-32,-96}.png, daal-favicon.ico
└── generated/               ← regenerated by tools/gen-assets.sh
                               (committed for now; Vite imports from here)
    ├── daal-flat/           (in-app vector + downscaled PNGs)
    ├── daal-3d/             (in-app hero rasters)
    └── launcher/
        ├── desktop/         (Tauri tray + window icons)
        ├── android/         (adaptive + legacy mipmaps)
        └── ios/AppIcon.appiconset/
```

## Background variants — which to use where

The mark exists in two background flavours. Pick by surface:

| Surface | Variant | Reason |
|---|---|---|
| Tauri desktop bundler (`*.deb`, `*.dmg`, `*.exe`, `*.msi`) | **bg** (white opaque) | The OS shell paints the icon on a square tile. Transparency reads as a bug. |
| iOS app icon (Springboard) | **bg** (white opaque) | Apple rejects transparency. Springboard masks corners itself. |
| Android launcher icon — legacy (Android ≤7) | **bg** | Same reason as desktop. |
| Android launcher icon — adaptive foreground (Android 8+) | **nobg** (transparent) | Background is a separate layer (solid `#033E51`). |
| System tray / menubar | **nobg** | Sits on the OS bar; transparency is required. |
| In-app sidebar / Welcome screen / hero | **nobg** (or SVG) | Sits on the app's teal canvas. |
| Web favicon | as-supplied | Browsers handle both. |

## Brand colour

The brand teal background is `#033E51` (sRGB) — the documented sRGB
approximation of the OKLCH `--bg` token in the app palette (see
`docs/daal-gui-design-brief-v2.md` §10). For Android adaptive-icon
background, the NSIS installer banner, and any on-device asset that
must render in sRGB only, use `#033E51` exactly so install-time and
runtime colours match.

## Regeneration

`tools/gen-assets.sh` regenerates everything under `generated/` plus
distributes platform-specific copies into:

- `client-shell/tauri/src-tauri/icons/` — read by Tauri's desktop
  bundler at `tauri build` time.
- `client-ui/public/` — served at site root for web favicons.

CI (`.github/workflows/release.yml`) runs the script in each `package`
job and copies the mobile launcher trees into the Tauri-scaffolded
`gen/android/.../res/` and `gen/apple/.../AppIcon.appiconset/` paths
after `tauri {android,ios} init` has run. This means the scaffolded
placeholder icons Tauri ships are overwritten with the real Daal art
before `tauri {android,ios} build` runs.

Manual regeneration (developer machine; requires ImageMagick `convert`,
optionally `png2icns` / `iconutil` for higher-quality macOS `.icns`):

```bash
bash tools/gen-assets.sh
```

The script is idempotent and deterministic — running twice on the
same inputs yields byte-identical outputs.
