# Censor Lab

Linux netns-based simulator for Iran-/China-class hostile network behavior.

See `specs/censor-lab-v1.md` for the specification and `specs/failure-taxonomy-v1.md` for the V0.3 failure categories the lab targets.

## Quick start

```bash
cd lab-driver
go build ./...
go test ./...

# Replay all scenarios into fixtures (no network privileges required):
./lab-driver replay --scenarios ../scenarios --out ../fixtures/failures

# Live run requires CAP_NET_ADMIN or root:
sudo ./lab-driver run --scenario ../scenarios/stateless-sni-rst.json
```

## What's inside

- `lab-driver/` — Go module (`daal/lab-driver`) implementing scenario parsing, fixture replay, and live-run orchestration.
- `scenarios/` — declarative YAML scenarios, one per simulated behavior class.
- `fixtures/failures/` — replayable JSON fixtures keyed to the failure taxonomy.
- `fixtures/reports/` — sample reviewed field-probe reports (test data only).
- `fixtures/pcaps/` — small synthetic pcap snippets generated by the lab itself.

## Privacy

The lab never touches real networks unless you explicitly point it at one. Scenarios use private address space (`10.0.0.0/8`, `192.0.2.0/24`) and self-signed certs. Fixtures must not contain real CDN IPs, real route secrets, or real user-identifying data.
