# Bundle Test Vectors

Bundle fixtures cover valid and invalid `.sbp` archives.

Initial cases:

- valid bundle
- invalid signature
- corrupt ZIP
- missing manifest
- missing publisher key
- expired route
- expired bundle
- changed publisher key
- valid key rotation placeholder
- revoked publisher
- revoked route
- wrong canonical JSON
- unknown route family
- path traversal in profile path
- malformed publisher key

Binary fixtures may be generated by `bundle-go` tests before being promoted to static files.
