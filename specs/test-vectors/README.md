# Test Vectors

This directory contains fixtures for Daal specs and reference implementations.

## Subdirectories

- `bundles/` — signed bundle package fixtures.
- `lifecycle/` — Route and Publisher lifecycle scenarios.
- `fingerprints/` — fingerprint rendering scenarios.
- `failures/` — failure-taxonomy fixtures used by later censor-lab work.

Fixtures must avoid real route secrets, real user identifiers, and real operational endpoints.
