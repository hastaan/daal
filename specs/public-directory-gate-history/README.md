# Public-directory gate evaluation history

This directory holds one file per quarterly evaluation of the FRP-13 public-directory gate. Each file records the verdict of `cmd/daal-gate-eval` at the date of the evaluation, together with any narrative context the operator wishes to preserve.

**Naming:** `<YYYY-Q[1-4]>.md`. Examples: `2026-Q2.md`, `2026-Q3.md`. One file per quarter.

**Append-only.** Earlier quarters' files are not edited after the evaluation; if a condition is later determined to have been met retroactively, the next-quarter file records the correction. The git tree is the audit trail.

**Schema:** mirrors `specs/public-directory-gate-v1.md`'s YAML block, plus a free-form `narrative` field at the top.

**Anti-vibe rule.** A quarter's file MUST be regenerated by `cmd/daal-gate-eval --json --quarterly > 20XX-QN.md` (the `--quarterly` flag is reserved for the post-track implementation phase; at FRP-13 ship the file is hand-written). Hand-written entries MUST cite the date and the gate-CLI exit code so reviewers can reproduce the evaluation.

The first entry, `2026-Q2.md`, is the FRP-13 ship evaluation. All six §17.2 conditions and all five §22.4 thresholds read HOLD; the verdict is HOLD.
